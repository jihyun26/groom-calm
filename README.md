# Moa — Adaptive Wellness MVP

지금의 상태와 가용 시간을 선택하면 호흡·명상·수면 사운드를 추천하고, 바로 실행할 수 있는 모바일 우선 웰니스 웹앱입니다.

> 이 앱은 의료 서비스가 아니며 진단이나 치료를 제공하지 않습니다. 사용 기록은 외부 서버가 아닌 사용자의 브라우저에 저장됩니다.

## 이번 작업의 주요 내용

- 첨부된 기술 명세서를 기준으로 모바일 우선 PWA 형태의 MVP를 구현했습니다.
- 참고 UI의 딥 네이비, 청록, 보라 계열을 반영해 몰입형 카드와 고정 하단 내비게이션을 구성했습니다.
- 상태 확인 → 규칙 기반 추천 → 세션 실행 → 평가 → 다음 추천 조정의 핵심 흐름을 구현했습니다.
- 별도 저작권 음원 없이도 동작하도록 Web Audio API 기반의 생성형 배경음을 사용했습니다.
- 새로고침 후에도 체크인, 세션 기록, 즐겨찾기와 설정이 복원되도록 브라우저 저장소를 연결했습니다.
- 앱 셸을 오프라인에서 다시 열 수 있도록 서비스 워커와 웹 앱 매니페스트를 추가했습니다.
- 플레이어를 닫거나 다른 화면으로 이동한 뒤에도 음악이 계속 재생되던 문제를 수정했습니다.

## 주요 기능

### 홈과 개인화 추천

- 마음 진정, 잠들기, 집중, 휴식 목적 선택
- 기분 1–5단계와 1·3·5·10·20·30분 가용 시간 체크인
- 목적, 시간, 즐겨찾기, 완료·중단 및 피드백 이력을 반영한 결정적 추천
- 추천 이유 표시 및 최근 세션 다시 듣기

### 세션 플레이어

- 1·3·5분 Quick Calm 호흡 세션
- 4초 들숨·6초 날숨의 시각 및 문자 안내
- 재생, 일시정지, 처음부터, 종료, 남은 시간과 진행률 표시
- 완료·중단 기록 및 도움 여부 평가
- 화면 이동, 페이지 종료, 새로고침 시 오디오와 타이머 정리

### 수면 모드

- 비, 파도, 숲, 모닥불, 화이트 노이즈, 브라운 노이즈 6종
- 최대 4개 사운드 선택 및 개별 볼륨 조절
- 15·30·60분 또는 직접 종료 타이머
- 모바일 브라우저 백그라운드 재생 제약 안내

### 탐색과 기록

- 호흡·명상·사운드 유형 필터와 검색
- 세션 즐겨찾기
- 완료 세션, 누적 이용 시간, 연속 이용일 및 최근 7일 기록

### 설정과 데이터 관리

- 모션 줄이기와 호흡 전환 진동 설정
- JSON 데이터 내보내기·가져오기
- 기기 내 전체 데이터 삭제
- 키보드 포커스, 44px 이상 터치 영역, `prefers-reduced-motion` 대응

## 실행 방법

별도 빌드나 패키지 설치 없이 정적 파일로 실행할 수 있습니다.

```powershell
cd adaptive-wellness/dist
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.

서비스 워커는 HTTP 또는 HTTPS 환경이 필요하므로 파일을 직접 여는 방식보다 로컬 서버 사용을 권장합니다.

## 프로젝트 구조

```text
adaptive-wellness/
├─ .openai/
│  └─ hosting.json
└─ dist/
   ├─ index.html              # 앱 셸과 메타데이터
   ├─ styles.css              # 디자인 토큰, 반응형 UI, 접근성 스타일
   ├─ app.js                  # 라우팅, 추천, 플레이어, 저장과 전체 상호작용
   ├─ manifest.webmanifest    # PWA 설정
   └─ sw.js                   # 앱 셸 오프라인 캐시
```

## 기술 구성

- HTML5
- CSS3 Custom Properties 및 모바일 우선 반응형 레이아웃
- JavaScript ES Modules
- Web Audio API
- Local Storage
- Service Worker 및 Web App Manifest
- Hash Router

## 데이터 및 개인정보

- 체크인, 이용 기록, 즐겨찾기와 설정은 현재 브라우저의 로컬 저장소에만 보관됩니다.
- 외부 분석 도구나 계정 시스템을 사용하지 않습니다.
- 사용자는 설정 화면에서 데이터를 JSON으로 내보내거나 전체 삭제할 수 있습니다.
- 브라우저 데이터 삭제 또는 저장 공간 회수 시 로컬 기록이 사라질 수 있습니다.

## 현재 MVP 제약

- 배포용 상업 음원이나 음성 명상 파일은 포함하지 않았습니다.
- 오디오는 Web Audio API로 생성한 간단한 환경음이며 실제 콘텐츠 음원으로 교체할 수 있습니다.
- 모바일 운영체제의 절전 정책에 따라 화면 잠금 중 재생 지속이나 정확한 종료 시각이 보장되지 않을 수 있습니다.
- 계정, 서버 동기화, 결제, 센서, 웨어러블 및 AI 추천은 포함하지 않습니다.
